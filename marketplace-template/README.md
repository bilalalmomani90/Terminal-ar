# متجر Terminal AR

هذا المستودع هو «متجر» ثابت لتطبيق Terminal AR: فهرس `index.json` موقَّع، وحزم `.tarpkg` معتمدة داخل `packages/`.
لا يوجد خادم. التطبيق يقرأ الملفات مباشرة من GitHub ويتحقق من التوقيع والبصمة قبل أي تثبيت.

## للمستخدمين
- في التطبيق: «الأدوات ← المتجر» (المشرف يضبط المستودع ومفتاح المراجِع مرة واحدة).
- وجود أداة هنا **لا يمنحها أي صلاحية**؛ الموافقة على الصلاحيات منفصلة.
- المراجعة ليست ضماناً مطلقاً للأمان.
- للإبلاغ عن أداة أو تقييمها: من زرّي «إبلاغ» / «تقييم» في التطبيق (يفتحان Issue هنا).

## للمطورين: كيف تنشر أداة
1. ابنِ حزمتك `.tarpkg` (من Studio في التطبيق).
2. افتح Pull Request يضيف ملف الحزمة داخل مجلد `submissions/` (وليس `packages/`).
3. اتبع قائمة التحقق في قالب الـ PR.
4. المراجِع يفحصها، فإن قبلها يوقّعها بمفتاح المتجر وينشرها ويحدّث الفهرس. قد يرفضها أو يطلب تعديلاً.
5. لا ترفع مفتاحك الخاص ولا أسراراً في الحزمة أو الـ PR.

## حالات الحزمة
مسودة (draft) ← قيد الفحص (scanning) ← قيد المراجعة (review) ← معتمدة (approved) أو مرفوضة (rejected).
بعد النشر: موقوفة (suspended) أو ملغاة (revoked). التطبيق يعطّل تلقائياً أي أداة مثبّتة بإصدار موقوف/ملغى.
الفهرس يعرض عادة المعتمدة والموقوفة والملغاة؛ أما المسودة/الفحص/المراجعة/المرفوضة فتُتابَع في الـ PR ولا يلزم نشرها في الفهرس.

## للمراجِع
الأدوات في `tools/market_tool.py` من مستودع Terminal AR. المفتاح الخاص يبقى على جهازك فقط.
